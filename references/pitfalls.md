# 踩过的坑（按代价排序）

只记真的浪费过时间的，不记常识。每条后面是「下次的检查」。

## 一、尺寸与字号

| 现象 | 原因 | 解法 |
|---|---|---|
| 文字莫名折行或溢出 | 预测量比 `_label` 的实际预算宽 8pt | 预测量统一用 `(w-0.2)*72-8`，不要自己另算一套 |
| 一排字号不一（54/48/40） | 每个元素各自缩到「刚好放下」 | 一排或一列先求统一字号（取最小值），再统一落 |
| 大字页占掉半屏、读不进去 | 长句 + `_fit` 取最大可用字号 | 长句上限 32pt、三行；大字页是让人停一拍，不是喊结论 |

## 二、颜色与主题

| 现象 | 原因 | 解法 |
|---|---|---|
| 白序号变绿、看不见 | 主题色解析漏了 `<a:sysClr lastClr>`，lt1 丢失 | 读整个元素；`theme_palette` 只留一份实现 |
| 深色满版块像贴纸 | 卡片比画布暗，读成凹陷 | 卡片比画布亮（.962 vs .90） |
| 「说不清哪里不对」的配色 | 只数饱和度，不看色相数与主次 | 跑 `palette_audit`：色相 ≤4、单页填充 ≤4、主元素 ≥38% |

## 三、检查器本身（误报会让人不再看报告）

| 现象 | 原因 | 解法 |
|---|---|---|
| 表格里标了 `[n]` 却报「列出未引用」 | 只读文本框，读不到表格单元格 | 遍历 `sh.has_table` 的所有 cell |
| 数据量尺被报「无锚点装饰线」 | 细长方形与分隔线同形 | 建形状时命名 `measure-*` / `track-*`，检查器放行 |
| 报「溢出 600pt」但页面正常 | 渲染器把同一行的标签与正文并成一个文本块 | 块宽 > 1.6× 所匹配框宽 → 视为合并块，跳过 |
| 页脚 `S2 p.2` 被拒 | 页码没挂文献编号 | 写成 `[n] S2 p.2` |
| 文献编号被重排 | `references()` 自动补 `[i]` | 条目已带 `[n]` 就用原编号；引用是子集，编号有缺口是常态 |

## 四、工具链与流程

| 现象 | 原因 | 解法 |
|---|---|---|
| 改了脚本没生效 | 同一秒内多次改同一文件，pyc 未失效 | 改完删 `__pycache__` 再跑 |
| 文件被改坏、代码拼歪 | `.replace` 的定位串撞上了别处同名片段 | 每次替换前 `assert old in s`，改完读回来核 |
| 保存报 PermissionError | 文件正在 PowerPoint 里打开 | 探测 `~$name`，**另存新文件名**，不抢用户窗口 |
| 示意图看着正常却没表达主张 | 固定偏移在小间距下退化 | 给图写几何断言（见 `check_schematic.py`），让图自己证明 |
| 画了半页又推翻 | 先排版后想内容 | 先写大纲与每页一句判断，再动手 |
