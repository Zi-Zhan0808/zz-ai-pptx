## 配色提示词（照抄，别改）

- **主色只有一个**：`#006334` 墨绿。它只出现在四个地方——序号圆徽、
  标题下的短横线、卡片顶部细线、强调字。其余面积一律不用纯绿。
- **表皮全是浅色**：画布 `#FFFFFF`、卡片 `#D9EFE5`、表格隔行 `#FFFFFF` /
  `#D9EFE5`。**不要**给标题条、表头、卡片顶栏填深绿——三块深绿并排会压过正文，
  这是这个模板被用坏的最常见方式。
- 正文墨色 `#1C2A24`（比纯黑柔一点，投影更耐看）；注释 `#5E6E66`。
- 一页最多 **两个** 视觉层级：`墨绿强调` 与 `浅绿面板`。需要第三种颜色时，
  改字号，不要加颜色。
- 不要用第二个色相。这个模板是单色系，加一个暖色就会立刻显出"拼的"。

## 内容提示词

- 六段式（可按需删减）：**基本信息 / 研究背景 / 研究思路 / 研究结果 /
  结论与讨论 / 创新点与启发**。目录条数必须与正文小节序号一致。
- 每页一句主张作标题，**≤ 24 个汉字**（超过就在 30pt 下折行撞标题带）。
- 一页一个结论；数据必须能落到具体页码或表号。
- 每页页脚写 `[n] p.N`，与参考文献页双向闭合。
- 课堂 pre 允许比组会少一些文献密度：一页 2–4 个要点，别铺满。

## 排版提示词

- 内容从 **1.31 in** 往下开始（标题带占 0.38–1.10 in，别压上去）。
- 左右边距 **0.56 / 12.83 in**，下沿 6.72 in，页脚 7.04 in。
- 卡片：圆角 0.055、浅绿底、**1.25pt 细边**、无阴影；2–4 张并排，不要 5 张。
- 序号：`page_number_badge` 里的数字是**白色**，压在版式的墨绿圆盘上。
  换颜色就看不见了——这条是从模板里读出来的，不是猜的。
- 封面/封底要放宽三处窄框（`文本框 10` 2.5in、`文本框 14` 2.6in、
  `文本框 11` 4.6in），否则四字以上的课题组名会折行。已写进 profile。
- 图：单图最大占 **10.4 × 4.9 in**；两图并排各 5.9in 宽；图注 12pt 居中。

## 已知取舍

- 这个模板没有小节分隔页。6 段汇报要么直接用序号圆徽换号，要么用
  `section_page()` 生成克制的分隔页（只有一个大号数字 + 一句标题）。
- 原模板的封面与封底各有 7 个变体，本文件只用了"满版墨绿"那一版。
- 图标库页面保留在文件里供参考，正式 deck 中不会出现。
